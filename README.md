## Project Overview

This project involves the design and simulation of a computer network for Kgwebo Grain & Feed in Klerksdorp.

The network will be designed and implemented using Cisco Packet Tracer to provide appropriate connectivity and network services while addressing the client's specified requirements and constraints.

## Client Requirements

- Provide appropriate network connectivity.
- Provide required network services.
- Use the assigned 10.20.0.0/16 addressing block.
- Ensure Management retains Internet access when the Staff network is restricted.
- Implement and demonstrate STP for loop prevention and root bridge design.
- Accommodate the planned branch office through addressing and design only.
- Produce a working and testable Cisco Packet Tracer implementation.
